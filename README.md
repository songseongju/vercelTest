# DEAD SIGNAL · LAST FIELD (v2.0)

Babylon.js 기반 싱글플레이 3D 배틀로얄. 플레이어 1명과 적 봇 12명이 전투합니다. 무기를 파밍하고 좁아지는 자기장을 피해 마지막까지 살아남으면 승리합니다.

## 플레이

- 무기 없이 시작하며, 시작 지점 바로 앞에 소총·탄약·구급팩·방탄복이 있습니다.
- 아이템 가까이에서 E 또는 모바일 획득 버튼으로 파밍합니다. 벽 너머 물건은 획득할 수 없습니다.
- AR-4 돌격소총, V-9 기관단총, DMR-7 지정사수소총을 찾아 보유하고 교체할 수 있습니다.
- 모든 총기는 공용 예비 탄약을 사용하며 탄창은 무기별로 보존합니다.
- 방탄복은 총탄 피해의 65%를 내구도 한도 안에서 흡수합니다. 자기장 피해는 방탄을 무시합니다.
- 치료는 3초 걸리며 구급팩 1개로 체력 65를 회복합니다. 사격하거나 총에 맞으면 치료가 취소됩니다.
- 적은 플레이어와 다른 봇을 발견하면 사격하며, 엄폐물에 가로막히면 우회하고 안전구역으로 이동합니다.
- 미니맵: 파란 원은 현재 자기장, 흰 원은 다음 안전구역, 삼각형은 내 위치입니다.
- 자기장은 반경 78m에서 50 → 30 → 15 → 4 → 0m로 줄어듭니다. 대기·축소를 합쳐 265초 후 완전히 닫힙니다. 구역 밖 피해는 단계에 따라 증가합니다.
- 일시정지하면 전투·자기장·치료·재장전 타이머도 멈춥니다.

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD, Shift 질주 | 왼쪽 패드 |
| 조준 | 마우스 | 오른쪽 영역 드래그 |
| 발사 | 왼쪽 클릭을 누르고 있기 | 발사 버튼 |
| 확대 조준 | 오른쪽 클릭 유지 | 조준 버튼 |
| 파밍 | E | 획득 버튼 |
| 재장전 | R | R 버튼 |
| 치료 | F | ＋ 버튼 |
| 무기 교체 | 1 / 2 / 3 | 교체 버튼 |
| 일시정지 | Esc 또는 Ⅱ | Ⅱ |

포인터 잠금이 불가능한 브라우저에서는 누른 채 드래그해서 조준할 수 있습니다. 시작/일시정지 화면에서 터치·마우스 조작, 선명·성능 화질, 사운드를 전환할 수 있습니다.

## 실행 및 Vercel 배포

정적 사이트이며 패키지 설치나 빌드가 필요하지 않습니다. 기존 vercel.json을 사용합니다. Vercel Framework Preset은 Other, Root Directory는 이 저장소, Build Command는 비워 둡니다.

로컬: `python3 -m http.server 8000` 후 http://localhost:8000 접속.
모바일: 배포된 HTTPS 주소를 Safari 또는 Chrome에서 여세요. iOS 카톡 첨부파일 미리보기 실행은 지원하지 않습니다.

## 파일

- index.html / style.css: 화면 및 모바일 조작 UI
- game.js: 전장, 이동·충돌·AI·사격·파밍·미니맵
- rules.js: 자기장 일정, 인벤토리, 피해·치료·재장전 규칙
- vendor/: 로컬 Babylon.js 엔진 및 라이선스
- star-dash.html: 기존 아케이드 게임

## 검증 및 범위

실제 Babylon.js의 NullEngine으로 파밍, 사격·재장전, 벽과 출입구의 시야 차단, 이동 충돌, 적 사격, 자기장 피해, 승패와 재시작을 검사했습니다. 별도 규칙 테스트로 5단계 축소·탄약 보존·방탄·구급팩 소비를 검사했습니다. 브라우저에서 PC와 모바일 가로 화면을 확인했습니다. 실제 iOS 하드웨어 테스트는 아직 하지 않았습니다.

이 게임은 간단한 로우폴리 그래픽의 오리지널 프로토타입입니다. PUBG/배틀필드의 코드·모델·음악을 사용하지 않으며 온라인 멀티플레이는 포함하지 않습니다.
